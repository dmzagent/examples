# Security Policy

## Reporting a vulnerability

Report security vulnerabilities through **GitHub private vulnerability
reporting** on this repository: open the **Security** tab and choose
**Report a vulnerability**. Reports filed that way are visible only to the
maintainers and never appear publicly.

**Do not open a public issue for a security vulnerability**, and please do not
disclose it publicly until a fix has shipped or we have agreed a date with you.

## What to include

- Affected component, and the version, tag or commit you tested
- Steps to reproduce, or a proof of concept
- The impact you believe it has, and any preconditions an attacker needs
- A suggested remediation, if you have one

## Response targets

| Stage | Target |
| --- | --- |
| Acknowledge receipt | 3 business days |
| Initial assessment and severity rating | 10 business days |
| Fix or documented mitigation, critical severity | 30 calendar days |
| Fix or documented mitigation, high severity | 90 calendar days |

These are good-faith targets for a small maintainer team, not a contractual
service level. If a report is being handled more slowly than this, say so on
the advisory thread and it will be re-prioritised.

## Scope

In scope: source code in this repository, its build and release workflows, and
its published artifacts.

Out of scope: findings that require a compromised maintainer account or
physical access; denial of service through unrealistic traffic volume;
vulnerabilities in third-party dependencies that have no exploitable path from
code in this repository (report those upstream, and tell us so the dependency
can be pinned or replaced); and reports generated by an automated scanner with
no demonstrated exploit path.

## Supported versions

Security fixes are applied to the default branch. There is no long-term support
branch, so upgrading to the current release is the supported remediation path.

## Disclosure

Reporters who wish to be credited will be named in the advisory. Tell us the
name or handle you want used; anonymous reporting is equally welcome.
